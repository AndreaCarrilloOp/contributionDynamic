# Brand

The contributionDynamic mark combines calendar cells and a moving D-shaped trajectory. The dark navy background represents the canvas; teal represents active contributions and their transformation.

| Color | Hex |
| --- | --- |
| Midnight | #0D1824 |
| Slate | #203543 |
| Teal | #148A83 |
| Mint | #5EEAD4 |

Use the original SVG at 48px or larger. Keep clear space around the icon. The wordmark is **contributionDynamic** (singular contribution, uppercase D). Tagline: *Beyond static contributions.*
