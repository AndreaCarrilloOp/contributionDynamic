# Contributing

Use Python 3.12+, create a virtual environment, and install with `python -m pip install -e ".[dev]"`.

Before opening a pull request, run `python -m pytest` and `python -m ruff check .`. Keep changes focused, document behavior, and never commit tokens or credentials.

Use deterministic test calendars and add tests for sparse, dense and empty inputs. Preserve cell coordinates, intensity levels and loop timing. Validate both themes and avoid external sprites or JavaScript in SVGs. The project uses the MIT license; contribute only material you have the right to license.
